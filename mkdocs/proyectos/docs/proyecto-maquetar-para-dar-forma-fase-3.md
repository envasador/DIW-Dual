## **Fases del proyecto**

### **Fase 3: Sistema de componentes visuales**

**Criterios:** RA2.g, RA2.e, RA2.f, RA1.f

#### **Tareas:**

1. **Mínimo 8 componentes UI completos**

   **Obligatorios (5):**

   * Botones (variantes, tamaños, estados)
   * Cards (2 variantes)
   * Formularios (inputs, textarea, select, checkbox, radio)
   * Navegación (header responsive, breadcrumbs)
   * Feedback (alerts/notificaciones)
2. **Adicionales (elige 3):**

   * Modales, Tablas responsive, Badges, Tabs, Paginación, Iconos
3. **Estados completos por componente**

   * hover, focus, active, disabled, error, loading
4. **Style Guide estático**

   * Página con todos los componentes y estados visibles
5. **Sección en DOCUMENTACION.md: "3. Sistema de componentes UI"**

   * Lista de componentes implementados
   * Nomenclatura y metodología aplicada
   * Capturas del Style Guide

#### **Entregables:**

* \[ \] 8+ componentes UI implementados
* \[ \] SCSS por componente
* \[ \] Style Guide funcional
* \[ \] Sección 3 del DOCUMENTACION.md completada
